好文章，留一份。
X → Markdown

在你自己的浏览器里导出已打开的文章。保留标题、作者、出处、段落、列表与图片链接，方便归档、阅读和提交翻译。

方式一 · 拖到书签栏

将下面的绿色按钮拖到浏览器书签栏。安装一次，以后打开文章点击书签即可下载。

↓ 导出 X 文章

显示书签栏：Mac 按 ⌘⇧B，Windows 按 Ctrl+Shift+B。直接点击此页按钮不会导出 X 文章。

方式二 · 固定到 Chrome / Edge 工具栏

  1. 下载并解压 扩展安装包。
  2. 打开 chrome://extensions（Edge 使用 edge://extensions），开启“开发者模式”。
  3. 点击“加载已解压的扩展程序”，选择包含 manifest.json 的文件夹，再把扩展固定到工具栏。

书签受页面策略或长度限制无法运行时，使用扩展版本。扩展仅申请当前标签页的临时访问和脚本执行权限。

每次使用，只需三步

  1. 打开 X 文章详情，展开全文并滚动到末尾，确保内容已经加载。
  2. 点书签或扩展图标，自动保存 文章标题.md。右下角可预览、复制或再次下载。
  3. 核对首尾内容。识别失败时，关闭提示面板，鼠标选中正文，再点一次导出。

图片保存为在线原图链接；视频与嵌入帖保留访问入口。工具无法验证页面是否已加载全部正文，也不导出评论区。无需 API Key，不读取 Cookie，不把文章上传到其他服务器。
